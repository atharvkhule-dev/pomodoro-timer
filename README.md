# 🍅 Zen Pomodoro Timer

A clean and minimalist Pomodoro Timer built with **HTML, CSS, and JavaScript** to help improve focus and productivity using the Pomodoro Technique.

🌐 **Live Demo:** https://pomodoro-timer-eta-ashen.vercel.app/

---

## ✨ Features

- ⏱️ 25-minute focus timer
- ☕ Short and long break sessions
- ▶️ Start, Pause, and Reset controls
- 📱 Responsive design for desktop and mobile
- 🎨 Clean, distraction-free user interface
- ⚡ Fast and lightweight (no frameworks)

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/atharvkhule-dev/pomodoro-timer.git
```

### Open the project

Simply open `index.html` in your browser.

Or, if you prefer using a local server:

```bash
npm install
npm run dev
```

## 📖 About the Pomodoro Technique

The Pomodoro Technique is a time-management method that breaks work into focused intervals (typically 25 minutes), separated by short breaks. It helps improve concentration, reduce burnout, and maintain productivity.
